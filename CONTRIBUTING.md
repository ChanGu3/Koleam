# Contributing To Koleam

This repository has two production applications that can ultimately come together as one.

The Full-Stack is the Web App and API Service that is bundled together and can be ran standalone with knowledge of the node package manager. See the Full-Stack [FS-CONTRIBUTING.md](/full-stack/FS-CONTRIBUTING.md)
 for more information.

The Desktop App is not a replacement for the Web App! It is introduced to provide a 'easy access' for those weith less experience to manage the server from a Graphical User Interface. It has the capability to run cli commands for those without a Desktop Environment. See the Desktop-App [DA-CONTRIBUTING.md](/desktop-app/DA-CONTRIBUTING.md) for more information.

## Full-Stack

Contains the source code for the server and the web client done in javascript.

Go to [FS-CONTRIBUTING.md](/full-stack/FS-CONTRIBUTING.md)

## Desktop-App

Contains the source code for the app manager to download, configure, and run the full stack effortlessly.

Go to [DA-CONTRIBUTING.md](/desktop-app/DA-CONTRIBUTING.md)

>## AI Policy
>
> The use of AI is not prohibited. Though Remember ANY and ALL contributions made by the author takes full responsibility of the code submitted and all it entails. Please follow the rest of the listed rules that will most likely continue to increase.
>
><!-- markdownlint-disable MD033 -->
> <b>Note:</b> If there is a good reason for the use of AI that breaks any of the rules make sure to include it in the issue and then wait for a member of the contribution team to okay it before getting started otherwise your work may not be accepted in this way.
>
> - <b>Documentation:</b> ABSOLUTELY NO AI MODEL USE IS ALLOWED FOR DOCUMENTATION
> - <b>Assistant Only:</b> Models should only be an assistant it should not be doing all the work for you...
> - <b>Generated Content:</b> No Unlicensed code. No Bad Code. No Vibe Code.
> - <b>Understandability:</b> If you cant explain in detail what has been generated then we wont even bother. PR Descriptions, review comments, Commits, Issue Reports, these are used as ways to communicate the project not for your AI generated responses.
> - <b>Verify:</b> Ensure what is being generated is human readable and stays within the scope and vision of the project.  
>
