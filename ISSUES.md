# ISSUES (Change Requests)

As Long as you follow all the rules mentioned you should be fine just make sure to use the template first and any other information you can write below it,

When creating an Issue ensure that its not to massive of changes to the code base regardless of it being a bug, enhancement, or new feature it must be not to large that it can be reviewed. IF YOU KNOW IT COULD POSSIBLE BE A LARGE CHANGE, please mark it as such so that it can be reviewed as this may be the only time a issue needs to be reviewed in such a manner to not waste time of the author creating the PR.

Issues can also be made by those unable to contribute but have found bugs or requesting features for the configuration app or the streaming app. Thanks if you do its a great help!
