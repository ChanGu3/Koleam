# Pull Requests

As Long as you follow all the rules mentioned you should be fine just make sure to use the template first and any other information you can write below it,

Your Pull Requests must be straight to the point and no over explaining unless necessary you can do so by placing some identifier possibly <b>MORE INFO:</b>, so those reviewing can use it as a way for additional help but shouldn't be the go to source of truth to understand what was done. Simple and Quick will make what you've done be pulled into main that much quicker!

You may expect questions and possible needs for refactoring before going forward with the pull request otherwise happy coding!
